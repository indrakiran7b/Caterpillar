# Caterpillar

Premium marketing site for Catterpillar, a technology-enabled reverse logistics and recycling startup.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
