# CaterPillar

Next.js website for CaterPillar, a doorstep scrap pickup product.

```bash
npm install
npm run dev
```

Production app and booking URLs are configured in `.env.local` using the keys in `.env.example`. Local-network APK paths should not be used.

There is no backend in this repository. Booking talks to `lib/api`. See `docs/API_INTEGRATION.md` for environment variables and mock mode.
